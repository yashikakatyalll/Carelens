🩺 CareLens

AI-powered at-home triage and skin health assistant designed to help users assess symptoms, explore care options, and find nearby healthcare resources.

Features

* AI-powered symptom analysis and triage
* Image-based skin and health assessment
* Personalized onboarding and health profile
* Nearby clinic and urgent care recommendations
* Health tracking
* Educational health guidance

Built With

* React
* TypeScript
* Vite
* Tailwind CSS
* Gemini API
* Netlify
